## Erstbesuch-Verhalten

| Option | Beschreibung | Gewählt (1. Runde) | Gewählt (revidiert) |
|---|---|---|---|
| Je Werkzeug einzeln | Zehn Merker, jedes Werkzeug erklärt sich beim ersten Öffnen | | ✓ |
| Einmal site-weit | Ein Merker, danach nie wieder | ✓ | |
| Je Werkzeug mit Verfallsdatum | Nach Monaten erneut | | |

**Wahl:** Je Werkzeug einzeln (revidiert)
**Notiz:** Zunächst „einmal site-weit" gewählt. Beim Zusammenfassen wurde die Folge benannt: Wer zuerst im Patch-Archiv landet — dem einfachsten Werkzeug — verbraucht dort seinen einen offenen Abschnitt und bekommt beim ersten Öffnen des Item Finders nichts mehr, obwohl das die erklärungsbedürftigen sind. Damit wäre das Phasenziel unterlaufen. Nach dieser Rückmeldung auf „je Werkzeug" revidiert; zehn Merker liegen in einem localStorage-Eintrag und sind baulich kaum teurer als einer.

| Option | Beschreibung | Gewählt |
|---|---|---|
| Der offene Abschnitt reicht | Der Knopf steht ohnehin sichtbar darin | ✓ |
| Ein Satz weist darauf hin | „Wissen, was die Knöpfe tun? → Elemente erklären" | |

**Wahl:** Der offene Abschnitt reicht
**Notiz:** Kein zusätzliches Element, keine Aufdringlichkeit.
