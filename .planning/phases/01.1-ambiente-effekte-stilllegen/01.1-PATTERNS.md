## Shared Patterns

### The `running`-boolean-at-reschedule gate (Pattern 1)
**Source:** `assets/archive.js:333, 398-419` (verbatim, unmodified, currently live for `visibilitychange`)
**Apply to:** `assets/detail.js` (`#stars`, `#embers`), `assets/archive.js` (extend, don't replace), all 38 patch-page inline `#stars` loops, and the `sc-4-2-0` outlier's rain/lightning loop (by hand).
```js
var running = true; // or false, if defaulting to FX-off at cold load
function frame() {
  if (!running) return;
  draw();
  requestAnimationFrame(frame);
}
```
The ONE required change at every site: gate the `requestAnimationFrame(frame)` call itself, not just the loop body — see RESEARCH.md "Anti-Patterns to Avoid" for why gating only the draw call (not the reschedule) fails FX-02.

### Pre-paint head flag + delegated toggle + cross-tab sync
**Source:** `src/layouts/Layout.astro:119-129` (head) + `:278-304` (body end)
**Apply to:** the new FX gate in the same file — same file, same technique, admin gate and OS-`auto` branch dropped, `vbfxchange` `CustomEvent` dispatch added (new, no analog needed elsewhere in repo since no other feature currently needs live cross-consumer wake-up).

### CSS hides the frozen last frame; JS stops the scheduling (Pattern 3)
**Source:** new rule, shape modeled on `Layout.astro:246-247`'s existing `html:not(.is-admin) .js-theme-toggle { display:none !important; }` attribute-selector idiom
**Apply to:** `assets/detail.css` (near `#stars`/`#embers`), `assets/archive.css` (near `.space__stars`, lines 163-178), and each of the 38 patch pages' inline `<style>` blocks (D-10 — this rule must be duplicated per-CSS-surface, not centralized, matching the "seitenlokal dupliziert" established convention this phase is explicitly not asked to undo).
```css
html:not([data-fx="on"]) #stars,
html:not([data-fx="on"]) #embers { display: none; }
```
