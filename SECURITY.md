# Sicherheit / Security

## Eine Lücke melden

Bitte **kein öffentliches Issue** und keinen öffentlichen PR für eine
Sicherheitslücke. Dieses Repository ist öffentlich; was hier steht, liest
jeder, bevor die Lücke geschlossen ist.

Stattdessen vertraulich melden:

1. **Per E-Mail** an die Adresse im
   [Impressum](https://verse-base.com/impressum/).
2. **Oder über GitHub,** sofern dort angeboten: Reiter *Security* →
   *Report a vulnerability* (private Meldung, nur für die Betreiber
   sichtbar).

Hilfreich sind: betroffene Seite oder Datei, Schritte zum Nachstellen, und
was ein Angreifer damit erreichen könnte. Bitte keine Daten anderer Nutzer
abrufen oder verändern, um die Lücke zu belegen; ein Nachweis am eigenen
Konto genügt.

Wir bestätigen den Eingang in der Regel innerhalb von drei Tagen und melden
uns, sobald die Lücke geschlossen ist.

## Reporting a vulnerability

Please do **not** open a public issue or pull request. Report privately by
e-mail to the address in the [legal notice](https://verse-base.com/impressum/),
or, where offered, via *Security* → *Report a vulnerability* on GitHub. Please do not
access or modify other users' data to prove an issue; a proof against your
own account is enough.

## Geltungsbereich / Scope

- die Website verse-base.com und staging.verse-base.com
- der Discord-Bot des Verse-Base-Servers
- der Code in diesem Repository
